# لوحة معلومات الفريق

واجهة لوحة معلومات باللغة العربية تساعد فرق التسويق على متابعة المهام والأحداث في واجهة واحدة واضحة.

## نظرة عامة
- يتم توليد أقسام الواجهة (الملخص، المهام، الأحداث) برمجياً لضمان اتساق النصوص والعناوين.
- البيانات الافتراضية معزولة في وحدة واحدة ويمكن استبدالها بسهولة بمصدر خارجي.
- تم التخلص من التعليقات العشوائية لصالح عناوين أقسام واضحة داخل الواجهة.

## أوامر التطوير
- `npm run dev`: تشغيل خادم تطوير بسيط لخدمة الملفات الساكنة على `http://localhost:4173`.
- `npm run lint`: فحص الشيفرة بحثاً عن تعبيرات تصحيحية أو مساحات زائدة.
- `npm run test`: تنفيذ مجموعة اختبارات وحدية خفيفة لضمان سلامة الملخص والواجهة.

## التشغيل والنشر
1. ثبّت الحزم الافتراضية المتاحة في النظام (لا توجد تبعيات خارجية مطلوبة لهذا المشروع).
2. لتشغيل نسخة محلية استخدم `npm run dev` ثم افتح المتصفح على العنوان الظاهر في الطرفية.
3. عند النشر، انسخ الملفات الساكنة (`index.html` ومجلد `src/`) إلى أي خادم HTTP بسيط أو خدمة استضافة ملفات (مثل GitHub Pages أو Netlify). لا يلزم بناء إضافي لأن الكود مكتوب كـ ES Modules تعمل مباشرة في المتصفح الحديث.
4. بعد كل نشر، نفّذ `npm run lint` و`npm run test` للتأكد من خلو الشيفرة من الأخطاء قبل مشاركة التغييرات.
